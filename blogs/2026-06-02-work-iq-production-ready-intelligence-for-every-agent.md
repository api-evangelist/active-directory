Microsoft announced the general availability of Work IQ API endpoints, a workplace intelligence layer enabling AI agents to access and reason over organizational data across Microsoft 365 and external systems. The platform combines chat, context, tools, and workspaces with built-in security and governance, operating independently of Microsoft 365 Copilot licensing on a consumption basis. Work IQ is available in public preview and supports high-volume, multi-step agent interactions through standard protocols.
